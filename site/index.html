Machine learning for brain–computer interfaces

Four BCI projects,
one for each product problem.

Decoding cursor movement, speech and arm movement from intracortical recordings, plus encoding camera images into visual-cortex stimulation. Each project has real public neural data where it exists, strong baselines, a closed-loop simulator, an interactive demo and a full paper.

How the four fit together

Three projects read from motor cortex and turn intent into action. Blindsight runs the other way: it writes into visual cortex. All four share the same constraints: few labels per person, signals that drift from day to day, tight latency, and a human in the loop.

What every project includes

Literature first

A reading-notes file per project that sets out the domain knowledge, the field's metrics and which published ideas each project builds on.

Honest evaluation

Standard baselines, held-out days, ablations and seeds. Every number on this site comes from a run in the repo.

Closed loop, simulated

Offline accuracy isn't the product. Simulated users drive each decoder through the real task, so the comparison is on bits/sec, success rate or recognition.

Scales to a GPU

The same code runs at small scale on a laptop CPU and at full scale on a CUDA GPU, using one script per project.
